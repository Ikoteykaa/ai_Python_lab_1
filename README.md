## 📌 Тема та мета роботи

**Тема:** Змінні, модель пам'яті, арифметичні оператори, функції введення/виведення (`print`/`input`), логічний тип `bool` та AI-асистований аналіз рішень[cite: 4].

**Мета роботи:**
1. **Практична:** Ознайомитися з середовищем виконання Python (3.10+) та навчитися правильно організовувати введення (`input()`) і виведення (`print()`) даних різних типів[cite: 4].
2. **Концептуальна:** Засвоїти фундаментальну різницю між змінною як коміркою пам'яті та змінною як посиланням на об'єкт, а також вивчити незмінні типи даних (`int`, `float`, `complex`, `str`, `bool`, `NoneType`)[cite: 4, 7].
3. **Обчислювальна:** Опанувати арифметичні оператори (`+`, `-`, `*`, `/`, `//`, `%`, `**`), їхні пріоритети, правоасоціативність та роботу з модуль-бібліотекою `math`[cite: 4, 9, 10].
4. **Інженерно-дослідницька (AI-компонент):** Сформувати культуру промпт-інжинірингу (роль, контекст, обмеження) та навчитися верифікувати та порівнювати власний код із кодогенерацією генеративних LLM-моделей[cite: 4, 11].
